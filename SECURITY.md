# Security policy

This repository is a static benchmark website. It should not contain credentials, private API endpoints, model access tokens, machine-specific logs, or model weights.

For a suspected vulnerability, use GitHub's private vulnerability reporting feature if it is enabled for the repository. Otherwise contact the repository owner privately rather than opening a public issue containing exploit details or secrets.

Only the latest `main` branch is supported. Media-content or benchmark-accuracy corrections may be reported through normal issues.

## 中文说明

本仓库是纯静态基准网站，不应包含凭据、私有 API 地址、模型令牌、本机日志或模型权重。安全漏洞应优先使用 GitHub 私有漏洞报告；不要在公开 Issue 中粘贴利用细节或密钥。当前只维护 `main` 分支。
